# تقرير اختبار أثر V2

كل قرار.. وأثره على شركتك كلها

اختبار Phase 16 راجع مسار ديمو روافد من تسجيل الدخول لحد المقارنة والحساسية، وبعدها اعتماد خطة المقاولات تحت نفس فرضية الائتمان وتصديرها. كل تشغيل استخدم قاعدة SQLite مؤقتة وخادم localhost. [خطة Phase 16](<local-path>) · [تقرير V1](QA_REPORT.md) · [اختبار المتصفح](phase16_browser.py)

## النتائج

`pytest -q` الكامل خلص بـ**378 اختبار ناجح و0 فشل** في 541.70 ثانية، منهم اختبارا Playwright على العرضين. ظهر تحذير الإهمال الموجود من Starlette/AnyIO. التشغيل استخدم `LLM_PROVIDER=rules` و`FORECAST_ENGINE=stat` للمجموعة العامة. اختبارا المتصفح شغّلا مسار Codex وTimesFM بالبدائل الثابتة. ## إعادة التشغيل

جهّز بيئة المشروع والأصول المحلية من README وChromium من Playwright مرة واحدة لو مش موجود. اختبار pytest بيبدّل مخرجات عامل TimesFM والـsubprocess الخاص بـCodex، مع تشغيل التطبيق والقاعدة والمتصفح والحساب والتصدير فعليًا. بذرة المقارنة 42. [تعليمات README](../README.md#اختبار-مسار-أثر) · [حالات pytest](../tests/test_p16_browser.py)

```bash
.venv/bin/python -m playwright install chromium
ATHAR_QA_SCREENS=qa/.work/phase16-offline .venv/bin/pytest -q -o addopts= tests/test_p16_browser.py
.venv/bin/pytest -q -o addopts=
```

التشغيل الحي استخدم TimesFM 2.0.2 مع أوزان النموذج 2.5 محليًا على CPU وCodex CLI 0.171.0. سكربت التجهيز سجّل البيئة المعزولة واعتمدها في سجل التنزيلات. الفحص الحي محتاج تسجيل دخول لـCodex، وبيشارك السؤال وبيانات الديمو اللي محتاجها المساعد. [إعداد TimesFM](../scripts/setup_timesfm.sh) · [تشغيل Codex](../app/llm/codex_cli.py)

```bash
bash scripts/setup_timesfm.sh
.venv/bin/python -m qa.phase16_browser --live --width 1440 --screens qa/.work/phase16-live
```

## حدود الفحص

- الاعتماد متاح لخطة قطاع محفوظة. في الاختبار، فرضية خفض الائتمان اتطبقت على المقاولات، وتأخير المورد اتحسب في التحليل المؤسسي. المقارنة والحساسية بتنزل Excel مباشرةً، وخطة القطاع بتتنزل بعد الاعتماد.
- نتيجة تجاوز الائتمان في السيناريو المختبر كانت 100% عند قيم الفرضيات المحددة، بعرض عدم يقين صفر. النتيجة خاصة بالديمو وإعداد اختبار الحلّال، واختبار واحد لـCodex بيغطي الصياغة المعروضة. في التشغيل الحي رجع أحد شروح القطاع للقواعد المحلية، وطلب المساعد المؤسسي احتفظ بمزوّد Codex.
- فحص الموبايل كان بمحاكاة عرض 390 بكسل في Chromium.
